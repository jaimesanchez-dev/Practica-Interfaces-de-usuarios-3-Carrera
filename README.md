🎒 Mochileros Sin Fronteras
Mochileros Sin Fronteras es una plataforma web diseñada para la exploración y reserva de experiencias de viaje alrededor del mundo. Ofrece una interfaz intuitiva, accesible y totalmente adaptada a las necesidades del viajero moderno.

🚀 Características Principales
Página de Inicio Interactiva (`Home.html`):
Carrusel de destinos destacados con navegación fluida.
Tarjetas de experiencias con funcionalidad para marcar favoritos ("Like") y acceso directo a la compra.
Galería de Destinos (`GaleriaDestinos.html`):
Filtros por medio de transporte (Avión, Barco, Tren, Autobús).
Búsqueda por palabra clave y filtrado por continentes.
Renderizado dinámico de tarjetas de destinos.
Formulario de Compra Dinámico (`FormularioCompra.html`):
Gestión completa de datos personales y métodos de pago.
Campos adaptativos para acompañantes, mascotas e intolerancias/alergias.
Internacionalización y Ajustes:
Selector de moneda (EUR, USD, YEN).
Selector de idioma (Español e Inglés).
Accesibilidad y Personalización:
Modos de visualización con soporte y adaptación para personas con daltonismo.
---
🛠️ Tecnologías Utilizadas
HTML5: Estructura semántica de la aplicación web.
CSS3: Estilos personalizados, variables CSS, layouts flexibles (`flexbox`/`grid`) y diseño adaptativo.
JavaScript (ES6 Modules): Lógica interactiva, manipulación del DOM, componentes dinámicos e integración de autenticación.
